# Reference site notes

Screenshot capture was not available in this environment (the browser preview pane could not
compositor-render for the screenshot tool), so this folder contains structural/text notes
gathered via DOM inspection instead of image files. Used as directional reference only —
no layout or copy is copied from these sites.

## aalto.finance — Aalto Finance

Squarespace-built site for the finance-focused student organisation at Aalto University.

- Header: logo left, single-row horizontal nav (Home / About / Partner Events / Open
  Positions / Our Events / Partners / Alumni / Quarterly / Contact / Links)
- Hero: full-width photo (city skyline with partner logos overlaid) + one-line bold
  statement heading, left-aligned
- Short "WHAT IS AALTO FINANCE" intro paragraph, generous line length, social links inline
- Partners shown as three tiers (Main / Corporate / Consulting), one logo each, plain —
  no cards, no borders
- Footer: flat link list + social icons, no heavy dividers
- Overall: content-led, minimal chrome, one accent colour, lots of white space

## aaltoaccounting.fi — Aalto Accounting

This is explicitly what the brief wants to avoid: a dated WordPress-style ainejärjestö
site — chronological news/blog list as the primary homepage content, small type, sidebar-like
stacking, no real hero. Useful as a negative reference (what "vanhanaikainen ainejärjestösivu"
looks like), not a visual influence.

## wave.ventures — Wave Ventures

VC fund site, not a student organisation, but included for its typographic confidence:

- Hero is almost entirely oversized bold sans-serif type ("BACKING THE NEXT GENERATION OF
  EXCEPTIONAL FOUNDERS EARLIER THAN ANYONE ELSE."), minimal supporting content
- Extremely sparse — the typography itself carries the entire opening statement
- Confirms the brief's "vahva hero" / "vahva typografia" direction: a homepage can open
  on type alone, no photography required in the very first view

## Takeaways applied to the Aktiiva concepts

- A hero can be type-led (wave.ventures) or photo-led (aalto.finance) — concepts should
  cover both, not repeat one approach five times
- Partner presentation should avoid equal-weight logo grids; aalto.finance's tiered,
  unboxed approach is closer to "ei geneerisiä korttirivejä" than a typical logo wall
- Navigation can be a plain single row, not a heavy institutional menu bar
- Avoid the aaltoaccounting.fi pattern entirely: no chronological news list as the
  homepage spine, no small dense type, no sidebar stacking
